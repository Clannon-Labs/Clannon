                             # ("...see the docs on usage limits: .../agent/#usage-limits"), and

                             # the dependency's prose (core/llm/failures.py::classify_failure),
                             # pinned by test_our_limit_breach_is_never_transient_whatever_its_
                             # message_says. The loop cap itself was never broken.
                             #
                             # Upgrade procedure + what must stay true:
