# Goal reports

Unified, cold-readable records for completed or paused multi-session goals.

Each report explains why goal existed, intended destination, execution method,
evolution, hurdles, changes shipped, evidence, remaining work, and final state.
These are frozen retrospectives. `docs/ROADMAP.md` remains live priority authority;
per-role `reports/` remain detailed evidence.
